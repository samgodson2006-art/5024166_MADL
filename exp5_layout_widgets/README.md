# Experiment 5: Flutter Layout Widgets

## Aim
To arrange interface elements with Flutter's basic and flexible layout widgets.

## Theory
- `Container` provides sizing, padding, color, and decoration.
- `Row` and `Column` arrange children horizontally and vertically.
- `Expanded` shares the available space along a `Row` or `Column`.
- `Stack` layers children, while `Positioned` places a child within it.
- `Wrap` moves children onto additional runs when space is limited.
- `GridView` displays children in a two-dimensional scrollable layout.

## Steps
1. Create a Flutter app with a `Scaffold` and a scrollable body.
2. Use a `Container` to demonstrate padding and decoration.
3. Arrange icons with a `Row` and text with a `Column`.
4. Compare space allocation using `Expanded` flex values.
5. Overlay a label on a background using `Stack` and `Positioned`.
6. Show wrapping chips and a two-column grid.

## Run
From this directory, run `flutter pub get`, then `flutter run`.
